# Gruppa Ost Stages 9/12 - native current-surplus observer and source authority.
# COUNTRY only except global configuration. No native resource/fuel writer.
# Dynamic queries are computed reads for literal installed native resource IDs;
# never use has_variable on a dynamic query. See design evidence E-037.
# Source mode 2 = native raw already-net surplus; 3 = plant-only policy zero.
# Stage 14 manufactured schema 3 never samples native resources or authored rates.
# Old manufactured source records are preserved and unavailable, not migrated.
# Stage 12 raw additions use schema 2. Legacy schema-1 authored records remain
# untouched and unavailable; no saved source authority or cadence is migrated.
# Source snapshots install only in begin-cycle, preserving all Stage 8 day tokens.
